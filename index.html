A temperature diary

We will store seven temperatures. Then we will count values from 18 to 26 and find an average.

  1. Read the short explanation.
  2. Copy the whole program into one .cpp file.
  3. Replace ____ with the missing part.
  4. Run the program. Compare it with the expected output.
  5. Go to the next step. Replace the old program with the new one.

One file, one program. Each step has a full program. Keep only one main() in your file. The range 18 to 26 is a rule for this exercise.

First, a small function

addTwo gets one number. x is its parameter. return gives the result back. The call addTwo(5) gives 7.

A complete example
#include <iostream>
using namespace std;

int addTwo(int x) {
    return x + 2;
}

int main() {
    cout << addTwo(5) << "\n";
    return 0;
}

Output: 7. Write this example and run it first if functions are new to you.

An average is a sum divided by a count. count is the number of values. sum * 1.0 makes a decimal calculation. average(sum, 7) passes two values.

A small reminder

Useful words

vector
A list of values. vector<int> stores integers.
index
The position of one value. The first index is 0.
parameter
A named input value inside a function.
argument
The value you pass when you call a function.
call
Use a function, for example addTwo(5).
return
Give the result back to the place that called the function.
bool
A type with two values: true and false.
average
The sum of the values divided by their count.
