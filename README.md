# C++ Labs

Simple English study guides for first-year C++ students.

## Lessons

- [Lab 8: Structures and student records](https://dozzka.github.io/CPP_LABS/lab8.html): six complete C++ programs, each with one gap, a short explanation, a hint, input and expected output. Includes a downloadable English presentation, an independent counter task and an optional ranking challenge.
- [Lab 7: Functions and vectors](https://dozzka.github.io/CPP_LABS/lab7.html): the previous temperature diary lesson and its worksheet.

The home page opens Lab 8. Both classroom subgroups use the same materials. Teacher scripts, teacher keys and complete solution files are stored outside this repository.

Students can check the expected gap, copy or download a program, and mark a step after running it in their own C++ compiler. The website does not compile or execute C++. Answers and progress are stored in this browser, separately for each lab.

## Run locally

Serve the repository with any static HTTP server, for example `python -m http.server 8000`, then open http://localhost:8000/.

## Publish

GitHub Pages publishes the root of main. The site is buildless: HTML, CSS, JavaScript and student downloads. All asset paths are relative and work under /CPP_LABS/.

## Files

- index.html and lab8.html: current structures lesson.
- lab7.html: preserved previous lesson.
- assets/site.css and assets/site.js: shared layout and practice controls.
- downloads/: student presentations, worksheets and incomplete programs.

The passing score 60 and the temperature range in Lab 7 are rules for these programming exercises.
