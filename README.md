# C++ Labs

Study guides for first-year C++ students in English, Russian, French and Arabic.

## Lessons

- [Lab 9: Which items are out of stock?](https://dozzka.github.io/CPP_LABS/lab9.html): review structures and vectors in three guided steps using a stationery shop.

- [Lab 8: Structures and student records](https://dozzka.github.io/CPP_LABS/lab8.html): six complete C++ programs, each with one gap, a short explanation, a hint, input and expected output. Includes an independent counter task and an optional ranking challenge.
- [Lab 7: Functions and vectors](https://dozzka.github.io/CPP_LABS/lab7.html): the previous temperature diary lesson and its worksheet.

The home page opens Lab 9. Both classroom subgroups use the same materials. Teacher scripts, teacher keys, slide files and complete solution files are stored locally outside this repository.

## Languages

The globe button opens the language chooser on desktop and mobile. It translates the explanations, tasks, hints, glossary and practice controls for the lessons. The choice is remembered across lessons and reloads. A URL such as [Lab 8 in Arabic](https://dozzka.github.io/CPP_LABS/lab8.html?lang=ar) can select a language directly; supported values are en, ru, fr and ar.

Arabic text uses right-to-left layout. C++ code, answers, identifiers and sample input/output stay unchanged and use left-to-right direction. The optional Lab 7 worksheet download remains in English.

Students can check the expected gap, copy or download a program, and mark a step after running it in their own C++ compiler. The website does not compile or execute C++. Answers and progress are stored in this browser, separately for each lab.

## Run locally

Serve the repository with any static HTTP server, for example `python -m http.server 8000`, then open http://localhost:8000/.

## Publish

GitHub Pages publishes the root of main. The site is buildless: HTML, CSS, JavaScript and student downloads. All asset paths are relative and work under /CPP_LABS/.

## Files

- index.html and lab9.html: stock review lesson, including offline practice.
- lab8.html: student records lesson.
- lab7.html: preserved previous lesson.
- assets/site.css and assets/site.js: shared layout, language chooser and practice controls.
- assets/i18n.js: authored translations for the lesson text and controls.
- downloads/: the English worksheet and incomplete C++ programs. Slide downloads have been removed.

The passing score 60 and the temperature range in Lab 7 are rules for these programming exercises.
