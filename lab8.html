A small student list

Each student has a name and a score. A struct keeps these values together. We will print a list, show students who passed, and find the best score.

  1. Read the explanation and task.
  2. Copy the whole program into one .cpp file.
  3. Replace ____ with the missing part.
  4. Run the program and compare the output.
  5. Replace the old program with the next step.

Input rules. Use one word for each name, with Latin letters. Scores are integers from 0 to 100. Step 1 has no input. Step 2 reads one student. Steps 3 to 6 read three students. Do not type a size first. The passing score is 60 for this exercise.

A complete example

Student is a type. student is one variable. student.name and student.score are its fields. A dot selects a field.

One student, two fields
#include <iostream>
#include <string>
using namespace std;

struct Student {
    string name;
    int score;
};

int main() {
    Student student;
    student.name = "Ali";
    student.score = 75;
    cout << student.name << " "
         << student.score << "\n";
    return 0;
}

No input. Output: Ali 75. Notice the semicolon after the struct.

A function for a student

isPassed gets one Student record and returns true or false. isPassed(student) checks one record. students[i] is the current Student record in the loop.

Pass the current record to isPassed. Replace ____ with one vector element.

Need a small hint?

Use the vector name students and the index [i]. Pass the whole record.

main.cpp 1 gap
#include <iostream>
#include <string>
#include <vector>
using namespace std;

struct Student {
    string name;
    int score;
};

bool isPassed(Student student) {
    return student.score >= 60;
}

int main() {
    vector<Student> students(3);
    for (int i = 0; i < 3; i++) {
        cin >> students[i].name;
        cin >> students[i].score;
    }
    cout << "All:\n";
    for (int i = 0; i < 3; i++) {
        cout << students[i].name << " "
             << students[i].score << "\n";
    }
    cout << "Passed:\n";
    for (int i = 0; i < 3; i++) {
        if (isPassed(____)) {
            cout << students[i].name << " "
                 << students[i].score << "\n";
        }
    }
    int best = 0;
    for (int i = 1; i < 3; i++) {
        if (students[i].score >
            students[best].score) {
            best = i;
        }
    }
    cout << "Best: " << students[best].name
         << " " << students[best].score << "\n";
    return 0;
}

A small reminder

Useful words

struct
A type with fields.
field
One value inside a record, for example score.
record
One Student value with its name and score.
dot
. selects a field, as in student.score.
index
A position in the vector. The first is 0.
best
The index of the student with the highest score in our program.
passed
A score of 60 or more in this exercise.
bool
A type with two values: true and false.
